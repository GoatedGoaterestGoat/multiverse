# Working worlds

Select a child universe and use the dashboard enter action. Use its parent/back action to return with navigation context preserved.

- stock-trading: fixed fictional portfolio, JSON and offline HTML.
- cad: mounting-plate dimensions, SVG, HTML and OpenSCAD text.
- cad/verification: analytical results with two intentional geometry failures.

Local command: `mv2 -u UNIVERSE command demo`. Artifact paths are relative to each universe root. Preview files are static fixtures, not live terminal evidence.
